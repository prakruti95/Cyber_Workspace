Practical 2: Network ID and Broadcast ID
For the following IP addresses, find:
•	Network ID
•	Broadcast ID
•	First Usable IP
•	Last Usable IP
•	Total Usable Hosts
IP Address	Subnet Mask
192.168.10.25	255.255.255.0
192.168.10.130	255.255.255.128
172.16.5.70	255.255.255.192
192.168.1.200	255.255.255.224
Answers
1. 192.168.10.25 /24
•	Network ID: 192.168.10.0
•	Broadcast ID: 192.168.10.255
•	First Usable IP: 192.168.10.1
•	Last Usable IP: 192.168.10.254
•	Total Usable Hosts: 254
