### Step 1: Block Size

`/25` → Subnet Mask = **255.255.255.128**

```text
Block Size = 256 − 128
           = 128
```

### Step 2: Range Selection

Last octet = **10**

Ranges:

```text
0   → 127
128 → 255
```

Since:

```text
0 ≤ 10 ≤ 127
```

So **10 belongs to the `0–127` range**.

```text
Network ID   = 192.168.1.0
Broadcast ID = 192.168.1.127

First Usable = 192.168.1.1
Last Usable  = 192.168.1.126

Total Usable Hosts = 128 − 2 = 126
```
